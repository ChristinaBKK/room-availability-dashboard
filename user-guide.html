Room Availability & Booking Dashboard

User Guide — B-Building Rooms, May–June 2026 Exam Period

This dashboard shows all scheduled lessons, exams, and room bookings for B-Building in real time. Use it to check which rooms are free, view what is happening in a room, and make ad-hoc room bookings that are visible to everyone instantly.

📅 Tab 1 — Schedule View

The main view. Shows all rooms for a chosen date and which sessions are running in each.

Filters

ControlWhat it does
DatePick any date. Defaults to today. The grid updates immediately.
RoomClick the button to open the room picker panel. Rooms are grouped by floor. Click one or more rooms to narrow the grid; click All Rooms to reset. The button label shows your selection. Rooms marked ✕ are blocked from booking but still shown for visibility.
Refresh NowForce-reloads all data from the database. Also available as an auto-refresh toggle (top-right).

Room cards

Each card represents one room. Inside you will see:

  • Session rows — time slot, class name, teacher name.
  • EXAM tag — this session is an official exam.
  • Exam Protection tag in the room header — the room has an exam the next day, so it should not be disturbed today.
  • A yellow banner at the card bottom naming the exam happening tomorrow and its time.
Rooms showing only an exam protection banner (no sessions listed) are free today but reserved for tomorrow's exam preparation.

Alerts

⚠ Room Booking Conflicts (red) — two different teachers are scheduled in the same room at an overlapping time. This needs to be resolved.
ℹ Special Attention (amber) — same teacher appears in two rooms at the same time, or some other scheduling overlap that does not constitute a hard conflict but is worth checking.
IBDP exam sessions sharing a room are intentional and are silently ignored by the conflict detector.

📝 Tab 2 — Book a Room

Reserve a room for an ad-hoc session. Bookings are saved to the database and appear immediately in the Schedule View for everyone.

How to book

1
Select a Room from the dropdown (blocked and exam rooms are excluded).
2
Pick the Date (defaults to today).
3
Enter Start Time and End Time.
4
Enter a Booking Title (e.g., "Mathematics Revision") and Your Name.
5
Optionally tick Recurring every week to repeat the booking on the same day each week.
6
The Available Rooms section below the form shows which rooms are free for the chosen date and time. Clicking a room name there auto-fills the Room field.
7
Click Book Room. A confirmation message will appear.
Bookings cannot be made on exam days or the day before an exam for rooms that are exam rooms. The system will show an error if you try.

📋 Tab 3 — All Bookings

A full list of every ad-hoc booking in the system (not regular lessons or exams). Use this to review or delete bookings.

  • Bookings are listed in chronological order.
  • Click the Delete button next to any booking to remove it. This is immediate and cannot be undone.

Exam Room Protection Rules

  • Exam rooms cannot be booked on the exam day.
  • Exam rooms cannot be booked the day before an exam.
  • This ensures rooms are always available and properly prepared.
